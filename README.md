# 🔐 Password Complexity Checker

## 📌 Project Overview
The Password Complexity Checker is a Python-based tool that evaluates password strength based on length, uppercase and lowercase letters, numbers, and special characters. It provides feedback to help users create stronger passwords.

This project was developed as part of **Task 03 – Cyber Security Internship at CodeCraft Infotech**.

## 🎯 Objectives
- Evaluate password strength.
- Check password length.
- Identify uppercase and lowercase letters.
- Check for numbers and special characters.
- Encourage strong password practices.

## 🛠️ Technologies Used
- Python 3
- String manipulation
- Conditional statements

## ✨ Features
- Password strength assessment.
- Checks for multiple password criteria.
- Provides feedback on password security.
- Simple and beginner-friendly implementation.

## ▶️ How to Run
1. Install Python 3.
2. Clone or download this repository.
3. Open the project folder in a terminal.
4. Run the program:

```bash
python password_checker.py
```

5. Enter a password when prompted and review the result.

## 📊 Evaluation Criteria
- Password length
- Uppercase letters
- Lowercase letters
- Numeric digits
- Special characters
